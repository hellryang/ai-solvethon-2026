## 5. 기술 사전과 점수 공식 (5분)

**기술 사전 (초안 20개)** — AI는 이 목록 안에서만 고른다. 위치: `backend/app/team/skills.py`

| 분야 | 기술 |
|---|---|
| AI·데이터 | 데이터 분석, 데이터 라벨링, 머신러닝, 컴퓨터 비전, 자연어 처리, 생성형 AI 활용, 시계열 예측 |
| 개발 | Python, 백엔드 API, 웹 프론트엔드, 모바일 앱, 데이터베이스, 클라우드 배포 |
| 현장 | IoT 센서, 임베디드 |
| 기획·디자인 | 서비스 기획, UI/UX 디자인, 데이터 시각화 |
| 운영 | 문서화, 고객 인터뷰 |

**관심 분야 = 기업 업종 (6개)**: 농업·식품, 제조·품질, 에너지, 관광·문화, 유통·물류, 공공·행정

**점수 공식 (100점, 추천)**

```
기술 점수 = (필요 기술 중 학생이 가진 수 ÷ 필요 기술 수) × 80
관심 가산 = 학생 관심 분야에 기업 업종이 있으면 20, 없으면 0
총점 = 기술 점수 + 관심 가산   (소수점 버림, 동점이면 일치 기술 수가 많은 순)
```

예: 필요 기술 4개 중 3개 보유 + 관심 일치 → 60 + 20 = **80점**

## 6. AI 지시문과 출력 형식 (3분)

제약: 응답 최대 256토큰, instruction 최대 300자, text 최대 4,000자, 팀 서버 분당 20회·하루 600회.
**기술 사전 목록은 instruction이 아니라 text에 넣는다** (instruction 300자를 아끼기 위해).

**출력은 JSON이 아니라 줄 단위 텍스트** — 256토큰에서 JSON은 잘리면 파싱이 깨진다. 특강 예제도 줄 단위 방식이다.

| 기능 | instruction 초안 | 출력 예 |
|---|---|---|
| ① 범위 정리 | 기업 요구를 정확히 3줄로 정리해 주세요. 목표: 한 문장. 기술: 함께 준 기술 목록에서만 최대 5개, 쉼표로 구분. 산출물: 최대 3개, 쉼표로 구분. 입력에 없는 사실이나 목록에 없는 기술은 쓰지 마세요. | 목표: 사진으로 불량 고구마를 분류하는 시범 모델<br>기술: 컴퓨터 비전, 데이터 라벨링, 웹 프론트엔드<br>산출물: 분류 모델, 라벨링 데이터셋, 결과 화면 |
| ② 추천 이유 | 학생과 프로젝트 정보를 보고 추천 이유를 2문장 이내로 써 주세요. 첫 문장은 일치하는 기술, 둘째 문장은 부족한 기술과 보완 방법입니다. 주어진 정보에 없는 경력이나 칭찬은 쓰지 마세요. | 컴퓨터 비전과 데이터 라벨링이 프로젝트에 바로 쓰입니다. 웹 프론트엔드는 부족하니 화면 담당 팀원과 함께하면 좋습니다. |

- 호출 시점: ①은 [AI로 정리] 버튼, ②는 [추천 이유 보기] 버튼을 누를 때만. **목록을 열 때 자동으로 부르지 않는다** (호출 한도).
- AI가 사전에 없는 기술을 쓰면 코드가 걸러낸다.
- 결정: 형식 그대로 ☐ / 수정 ____

## 7. 화면 구성과 시연 시나리오 (4분)

```
┌ 잇다랩 ─────────────────────── [ 기업 ] [ 학생 ] ┐
│ 기업 탭                                            │
│  "AI로 어떤 일을 해결하고 싶나요?" [입력창]          │
│  [AI로 범위 정리] → 목표 / 기술 칩 / 산출물 (수정 가능) │
│  [프로젝트 등록] → 등록 목록 → 선택하면              │
│     추천 학생 TOP 3: 80점  ✓컴퓨터 비전 ✓라벨링 ✗웹   │
│                      [추천 이유 보기]                │
│ 학생 탭                                            │
│  [가상 학생 선택 ▼] → 나에게 맞는 프로젝트 (점수순)    │
│     카드: 기업명 · 전남 영암군 · 80점 · ✓/✗ 칩 · ☆    │
│  [저장한 프로젝트]                                  │
└───────────────────────────────────────────────────┘
```

로그인은 없다. 학생 탭은 가상 학생 10명 중 한 명을 고르는 방식이다.

**시연 시나리오 (발표 3분)**
1. (기업 탭) "불량 고구마 고르는 데 사람이 너무 많이 들어요" 입력 → [AI로 범위 정리]
2. 목표·기술·산출물이 정리됨 → 기술 하나를 고치고 등록
3. 추천 학생 TOP 3와 ✓/✗ 칩 → [추천 이유 보기]
4. (학생 탭) 그 학생으로 전환 → 같은 프로젝트가 상위에 뜸 → ☆ 저장
