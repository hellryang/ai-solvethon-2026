# 계산 기준과 심사 예상 질문

> 10/30 20:30 확정. "남는 돈" 계산의 모든 기준, 근거, 그 기준을 고른 이유를 한곳에 모았다.
> 심사위원이 숫자를 물으면 이 문서로 답한다. 코드는 `backend/app/team/savings*.py`, 기댓값 테스트는 `tests/test_savings.py`.
> 기준을 바꾸면 테스트·발표 숫자·이 문서를 같이 고친다.

## 1. 한 줄 공식

```
월 남는 돈 = 월 실수령액 − 월세 − 교통비 − 생활비 − 자차 고정비(차가 있을 때) + 월세 지원금
```

서울과 전남·광주에 **같은 공식**을 쓴다. 금액은 코드가 계산하고, AI는 코드가 넘긴 숫자만 인용한다.

## 2. 기준 12개

| # | 기준 | 값 | 근거 | 이렇게 정한 이유 |
|---|---|---|---|---|
| R1 | 연봉 | 고용24 공고의 **하한값**. "월 500만원 이상"은 6,000만원, "비공개"는 제외 | 고용24 채용 공고 24곳 (서울은 강남·중구 8곳 사용) | 신입 기준이고, 높은 값을 고르면 숫자를 부풀렸다는 지적을 받는다 |
| R2 | 실수령액 | 연봉별 월 실수령액표. 표 사이 값은 직선 보간 | 1인, 비과세 식대 20만원, 2026 4대보험 요율(국민연금 4.75%, 건강 3.595%, 장기요양 13.14%, 고용 0.9%), 지방소득세 포함 | 공고가 정규직이라 프리랜서 3.3%를 쓰면 틀린다 |
| R3 | 사는 곳 | 본가이고 근무지가 같은 시면 월세 0 + 시내버스. 광주↔나주 본가면 월세 0 + 광역버스. 그 외(자취·모름·타 지역)는 근무지에서 자취. **서울은 항상 그 구에서 자취** | AI는 거주 시군과 본가·자취만 뽑고, 판정은 코드가 한다 | 타깃은 광주·전남에 사는 청년이다. 서울 근무는 이주를 전제한다. "모름"은 자취로 본다(보수적) |
| R4 | 교통비 | 월 40회(통근 20일). **K패스 청년 30% 환급을 양쪽에 적용**. 광주 35,000 · 나주 40,600 · 광양 42,000 · 서울 43,400 · 광주↔나주 광역 56,000원 | 각 시 요금표, 서울 지하철 기본요금. 광역은 광주 탑승 1,250 + 나주 탑승 2,750 = 하루 4,000원 | 전국 제도라 양쪽에 같이 적용한다. 광역 요금은 11만원(2,750 × 40)이 아니라 실제 요금 구조인 8만원을 쓴다 |
| R5 | 자차 | 차가 있으면 **보험·세금 110,369원을 서울과 전남 양쪽에** 넣는다. 통근은 버스와 자차 유류비 중 싼 쪽. 정비비 제외 | 보험: 보험개발원 2025 평균 68만원 × 최초 가입 할증 1.52. 세금: 지방세법 1,598cc. 유류: 오피넷 1,856.6원/L, 13km/L, 광주↔나주 왕복 48km(네이버지도) | 차가 이미 있으면 어디서 일하든 보험·세금은 낸다. 전남만 떠안게 하면 불공정하다. 광주↔나주 자차 유류비 137,103원은 버스 56,000원보다 비싸서 버스를 탄다 |
| R6 | 월세 지원금 | 요건을 충족하는 제도 중 총액이 큰 1개(중복 불가). 나이는 만 25세 가정. 지원 기간만큼만 더한다 | 국가 청년월세(본인 소득 중위 60% 이하), 나주시 청년 취업자 주거비(150% 이하, 월세 60만원 이하), 서울시 청년월세(48~150%, 월세 60만원 이하). 광양은 제도 없음 | 추첨·선정제라 "보장 아님"을 화면에 표시한다 |
| R7 | 생활비 | 월 120만원, 양쪽 같은 값 | 국가데이터처 1인 가구 월평균 소비지출 168.9만원에서 주거 18.4%·교통 10.6%를 뺀 값 | 양쪽 같은 값이라 비교 결과는 바뀌지 않고, 남는 돈의 절대 금액만 현실적으로 만든다 |
| R8 | 손익분기 X | X = (서울 비용 − 전남 비용) ÷ 전남 월 실수령액 | — | "서울 실수령이 X% 더 많아야 남는 돈이 같아진다" |
| R9 | 실제 격차 g와 메시지 | g = (서울 실수령 − 전남 실수령) ÷ 전남 실수령. X − g > 5%p → "남으면, 남는다." / ±5%p → "비슷하다" / 그 아래 → 역전 지원금 S 표시 | 항등식: 월 차이 = 전남 실수령 × (X − g) (테스트로 고정) | 숫자를 꾸미지 않고 결과에 맞는 메시지를 고른다 |
| R10 | 역전 지원금 S | S = max(0, 서울 남는 돈 − 전남 남는 돈), 월 단위 | — | 서울이 더 남는 경우 "지원금이 월 S원이면 역전"을 보여 준다. 지자체 정책 도구가 된다 |
| R11 | 추천 점수 | 기술 = (보유 일치 + 확장 일치 × 0.5) ÷ 필요 기술 수 × 80, 소수점 버림. 근무 조건 상주·무관이면 +20, 재택 0. 동점은 보유 일치 많은 순 → 연봉 하한 높은 순 → id 순. **추천은 전남·광주 12곳만** | 공고는 모두 정규직 상주 | 서울은 선택지가 아니라 기준선이다 (취지) |
| R12 | 같은 일 서울 공고 | 필요 기술이 가장 많이 겹치는 서울 공고 → 기술 구성이 더 비슷한 순(Jaccard) → **서울 연봉이 높은 순** → 목록 순 | 연봉 비공개 1곳 제외 | 동점일 때 전남에 불리한 쪽을 골라 "유리한 것만 골랐다"는 지적을 막는다 |

## 5. 심사 예상 질문과 답

| 질문 | 답 |
|---|---|
| 왜 연봉 하한값인가? | 신입은 하한에 가깝게 받는다. 높은 값을 쓰면 우리 결론이 부풀려졌다는 지적을 받는다. 서울 공고도 같은 규칙이다 |
| 세금을 어떻게 뺐나? | 정규직 공고라 2026 4대보험 요율과 근로소득세(지방소득세 포함)를 반영한 실수령액표를 쓴다 |
| 영등포는 왜 없나? | 서울 기준선을 강남·중구 두 곳으로 정했다. 대신 동점일 때는 연봉이 높은 서울 공고와 비교하고(R12), 서울이 이기는 경우도 그대로 보여 준다(사례 C, 역전 지원금 S) |
| 강남 월세 69만원은 너무 비싼 곳만 고른 것 아닌가? | 국토부 실거래 6개월치 1,955건의 중앙값이다. 중구(52만원)도 함께 쓴다 |
| 본가에서 다니면 당연히 유리한 것 아닌가? | 맞다. 그게 이 서비스가 보여 주려는 지역의 실제 장점이다. 서울에서 본가 출퇴근이 안 되는 광주 청년에게 이 차이는 현실이다. 자취하는 경우(사례 C)도 같은 공식으로 계산한다 |
| 차 있는 사람은? | 보험·세금은 서울과 전남 양쪽에 똑같이 넣는다. 통근은 버스와 자차 유류비 중 싼 쪽으로 계산한다(R5) |
| 지원금을 다 받는다고 가정했나? | 아니다. 요건을 하나씩 판정한다. 국가 청년월세는 본인 소득이 연 1,846만원 이하라 공고 24곳 모두 해당이 없다. 강남은 월세가 60만원을 넘어 서울시 지원 대상이 아니다. 받더라도 추첨·선정제라 "보장 아님"을 표시한다 |
| 생활비는 왜 같나? | 지역별 1인 가구 생활비 공식 통계가 부족하다. 서울이 더 비쌀 가능성이 높지만, 보수적으로 같은 값을 넣었다 |
| 정비비는? | 공식 통계가 없어 뺐다. 우리 자차 비용(보험·세금·유류 약 25만원)은 이미 민간 설문의 차주 월평균 유지비(약 22.6만원)보다 크다 |
| 데이터가 가상 아닌가? | 월세·요금·지원 제도·연봉 공고는 모두 실데이터다. 화면의 회사명만 가렸다 |
| AI를 빼면 계산기 아닌가? | 금액은 일부러 코드로 계산한다(같은 입력 → 같은 결과, 테스트로 고정). AI는 자기소개 해석(서버 검증 10/10), 금액 밖의 장단점 분석, 준비 로드맵이라는 세 가지 다른 일을 한다 |

## 6. 알려진 한계 (질문받으면 인정한다)

- 보험 할증 52%는 2016년 금감원 보도 기준이다. 20대 연령 할증은 빠져 있어 실제 보험료는 더 높을 수 있다 (양쪽에 같이 들어가 비교 결과는 바뀌지 않는다)
- 유가는 광주 단독 값이 아니라 전국 평균이다
- 나주·광양 월세는 표본이 80건 이하다
- 서울 교통비는 지하철 기본요금 기준이고, 환승·거리 추가요금은 반영하지 않았다
