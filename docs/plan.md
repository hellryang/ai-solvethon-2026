## 2. 최종 컨셉: 핵심 기능 3개

| # | 기능 | 코드가 하는 일 | AI가 하는 일 (Bedrock, 응답 256토큰) | 왜 넣나 |
|---|---|---|---|---|
| ① | **내 이야기 → 전남 프로젝트 추천** | 적합도 점수로 상위 3건을 고른다. 카드마다 "강남보다 월 +OO만원" | 이야기 한 줄에서 기술, **확장 기술**(예: Java 경험 → Spring·공공 SI), 조건(본가 출퇴근·차량·근무 형태)을 뽑아 토글을 미리 채운다 | 키워드 매칭의 좁음을 AI의 이해로 넓힌다 (멘토 05:34) |
| ② | **남는 돈 + 기업 장점 비교** | 월 순저축, 두 줄 누적 막대, 손익분기 X%, 역전 지원금, 기업 장점 태그 | [분석 보기]를 누르면 "나에게 맞는 점 / 아쉬운 점 / 한 줄 판단" | 돈만이 아니라 지역 기업의 장점까지 보여 준다 (01:16). 목록이 아니라 분석이다 (04:41) |
| ③ | **1~3순위 → 준비 로드맵** | 2년·5년 누적 막대 (정착 그림) | 선택한 회사 기준으로 1·3·6개월 준비 항목(지역 기술 포함), 자격증, 1년 경력의 의미 | 취업 준비로 이어지는 그림이 생긴다 (05:56, 09:15) |

**계산 원칙**
- 서울과 전남에 같은 공식을 쓴다
- 생활비, 건강보험·연금은 양쪽에 같은 값을 넣는다 (보수적 가정)
- 차량비에는 보험·유류·정비를 모두 넣는다
- 월 금액은 지역 연봉 통계 ÷ 12로 잡고, 프로젝트는 기간만큼 누적한다
- 출처와 기준일을 화면에 표시한다
- 손익분기 `X = (서울 비용 − 전남 비용) ÷ (전남 월 금액 × (1 − 세율))`

**메시지 판정** (g = 실제 임금 격차. 숫자는 꾸미지 않는다)

| 결과 | 쓸 메시지 |
|---|---|
| X가 g보다 5%p 넘게 크다 | "남으면, 남는다." |
| 차이가 ±5%p 안 | "연봉은 서울이 높아도 남는 돈은 같다" + 본가 출퇴근·지원금 시나리오 |
| X가 g보다 5%p 넘게 작다 | 대표 시연을 광주 본가 → 나주 출퇴근(월세 0)으로 바꾼다 |
| g를 못 구함 | "같은 단가면 월 +OO만원, 강남은 X% 더 줘야 같아짐" |

**빼는 것**: 팀 매칭, 커뮤니티, 기업 후기 수집, 기업용 화면, 관심 저장(DB), 로그인, 지도, 모바일

**시연 흐름 (2분 40초)**
1. "광주 본가, 차 없음, 학부 때 Java로 학사관리 웹을 만들어 봤고 상주 근무 괜찮음"이라고 입력한다 → AI가 읽은 기술·확장 기술·조건이 토글에 채워지고 상위 3건이 뜬다
2. 나주 공공 SI 프로젝트 카드를 누른다 → "강남보다 월 +OO만원"과 장점 태그 → 두 줄 막대 → 손익분기 → [분석 보기]
